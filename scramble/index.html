THE RECIPE

Make a word.
Change the board.

Trace 4–16 side-sharing tiles. No diagonals, repeats, or tiles from submitted words. Use at least one filled and one empty tile.

Type missing letters; filled ones skip. Enter locks a word, Esc clears. On phones, tap the preview to type; arrow keys and Space select by keyboard.

New letters score their value +2. Mint +5 and pink ×2 work once. Fill all 64 tiles for +50. The run ends when time runs out, the board fills, or no moves remain.

Everyone gets the same daily board. The open word list isn't official Scrabble; DEV / RESEED is practice.
